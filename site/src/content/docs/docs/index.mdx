pillar-csi is a Container Storage Interface (CSI) driver for Kubernetes. It creates block volumes in the ZFS pools and LVM volume groups on your storage nodes, or filesystem datasets in ZFS, and serves them to pods over NVMe-oF/TCP, iSCSI, or NFSv4.2.

The driver's container images carry every user-space tool it runs, so your hosts need only the kernel support and storage required by the protocol and backend. NVMe-oF/TCP, iSCSI, and NFSv4.2 ship today; SMB is planned and unavailable.

If you have not installed pillar-csi yet, start with the tutorial. It takes you from one storage node to a pod with a mounted volume.

pillar-csi does not replicate data. Each volume lives on one storage node, so the volume is unavailable while that node is down. The [architecture page](/docs/explanation/architecture/) explains the data path in detail.
