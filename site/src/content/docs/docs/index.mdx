pillar-csi is a Container Storage Interface (CSI) driver for Kubernetes. It creates volumes in the ZFS pools and LVM volume groups on your storage nodes, and the Linux kernel serves them to pods over TCP, with the NVMe-oF target or the LIO iSCSI target.

The driver's container images carry every tool it runs, so your hosts need only the NVMe-oF or iSCSI kernel modules and a ZFS pool or LVM volume group. NVMe-oF/TCP and iSCSI ship today; NFS and SMB are planned.

If you have not installed pillar-csi yet, start with the tutorial. It takes you from one storage node to a pod with a mounted volume.

pillar-csi does not replicate data. Each volume lives on one storage node, so the volume is unavailable while that node is down. The [architecture page](/docs/explanation/architecture/) explains the data path in detail.
