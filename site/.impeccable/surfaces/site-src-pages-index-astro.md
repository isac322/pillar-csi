# Landing surface brief

Scope: site/src/pages/index.astro (landing, Persuade mode). Docs (/docs/, Read mode) share the tokens.
Redesign of the look only: content comes from src/data/landing.ts; section order, star nudge, copy buttons and scroll hints stay. World and composition were fixed by the owner, so no concept roll ran.

## Direction contract

THESIS: A storage node is a machine you keep on the bench. The page is that machine's enamel body and brass nameplate, and refuses the neon-on-black dev-tool hero.

OWN-WORLD: Deep Enamel ground, Machine Green enamel plates for featured fields, Enamel Cream type, Steel for shading and secondary text, Brass as the one accent: the data path and the primary action. Archivo Expanded Bold in stamped uppercase for labels and display; JetBrains Mono only for commands, paths and device names. Plates have 6px corners; controls 4px.

STORY: The visitor sees the pool-to-pod path drawn in brass, reads the one-line claim, copies the install command, and follows the quickstart.

FIRST VIEWPORT: Left: nameplate tag, H1 in Archivo Expanded, subline, install well, brass primary button. Right: the schematic mounted on a Machine Green plate.

FORM: Machine drawing on an enamel casting; a stepped cast-foot rule closes the hero.

MEMORABLE: The single brass line from kernel nvmet to /dev/nvmeXnY.
